# DBW News — dbw-news.com

This branch holds the DBW News website (Dynamic Black Women Media) and is
separate from the Hill Country Consultants site on `main`. The two branches
share no files.

- `site/` — the static website. Start with `site/README.md`.
- `supabase/migrations/` — the database: accounts, membership levels, the
  issue archive and the private bucket for page scans.
